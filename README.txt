あおぎり高校 学生証ジェネレーター
==============================

使い方
 1. 下記の配布ページからテンプレート画像 image-web.jpg をダウンロードします。
      https://ci-en.net/creator/24401/article/1989937
 2. このフォルダの index.html をブラウザ（Chrome / Edge / Firefox / Safari）で開きます。
    （ZIP の場合は任意のフォルダに展開してから開きます）
 3. 「テンプレート画像」で image-web.jpg を選択します（プレビューへのドラッグ＆ドロップも可）。
    SHA-256 が配布元の画像と一致した場合のみ読み込まれます。
 4. 写真を選び、枠内のドラッグ（移動）・ホイール（拡大縮小）やスライダーで調整します。
 5. フォームに文字を入力し、「PNG で保存」を押します。

メモ
 - テンプレート画像はこのツールに含まれていません。各自で配布元から入手してください。
 - インストールやサーバは不要です。すべてブラウザ内で処理され、外部に送信されません。
 - 「このブラウザに保存」にチェックがあると、検証済みのテンプレートが
   ブラウザ内 (IndexedDB) に保存され、次回から自動で読み込まれます。
   「保存したテンプレートを削除」で消せます。
 - 期待するハッシュ値 (SHA-256) は app.js の EXPECTED_SHA256 にあります。
 - 書体は OS にインストールされているフォントを使用します。

利用条件（配布元より）
 - 個人で楽しむ範囲、SNS への投稿は自由
 - テンプレートの再配布、加工後の二次配布、商用利用は不可
 - 公序良俗に反する使い方は不可
 非公式のファンメイドツールです。テンプレートの著作権は あおぎり高校 / viviON Inc. に帰属します。
